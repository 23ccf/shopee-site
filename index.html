GitHub Token 设置

为什么需要填 Token：「删除选中」会直接把商品从 GitHub 源 catalog.json 永久移除，并写入 deleted.json。扩展安装在跨境卫士，无法打开本网站，因此不能帮网站写 GitHub，必须在本站填写 Token。

请填入具备 Contents: Read and write 权限的 PAT（与录制器扩展里填的是同一个）。Token 仅存于本浏览器 localStorage。
